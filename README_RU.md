# SpaceGram

SpaceGram — экспериментальный open-source и неофициальный клиент Telegram для iOS. Основой служит Telegram-iOS, собственный код продукта находится в `SpaceGram/`, а небольшие точки интеграции в upstream-модулях явно отмечены.

## Текущие функции

- Одна строка **SpaceGram** в настройках Telegram открывает сгруппированный центр настроек.
- **Режим «Призрак»** использует один постоянный глобальный переключатель для присутствия в сети, набора текста/активности, автоматического прочтения и просмотров историй. Активность речи в групповом звонке остаётся штатной, чтобы звонки продолжали работать.
- **Чтение при взаимодействии** может подтвердить прочтение только после успешной явной облачной отправки или реакции. Открытие, просмотр, прокрутка, набор текста и постановка отложенного сообщения в очередь чат не читают.
- **Отложенная отправка** планирует поддерживаемые обычные сообщения не раньше чем через 12 секунд по скорректированному серверному времени Telegram и повторно проверяет время после загрузки медиа.
- При обычном открытии чата в режиме «Призрак» показываются последние сообщения без изменения серверного непрочитанного состояния. Явные переходы к сообщению, поиску, ответу, упоминанию, закреплению, дате и deep link имеют приоритет.
- Удалённые облачные сообщения показываются через локальный overlay конкретного аккаунта. Исходный текст не меняется, удаление отмечается компактной подписью рядом со временем.
- **Медиаархив** сохраняет полные ресурсы, уже полученные текущим аккаунтом. Если байты не были получены, медиа остаётся недоступным; секретные чаты исключены.
- Необязательные действия меню: «Снимок», «Сохранить защищённое медиа», «Переслать как новое» и «Переслать без имени». Они независимы и по умолчанию выключены; недоступное действие не имитируется.
- В центре настроек доступны ID профиля, исходящий перевод, правила inline-ботов, оформление, приватность и сохранённые расширенные настройки.

Удалённые SpaceGram AI/Qwen и собственные QR Tools не входят в продукт. Штатные QR-сценарии Telegram сохранены.

## Архитектура

```text
Telegram-iOS upstream
    ↓ отмеченные точки интеграции
Настройки, политики, локальное хранилище и UI SpaceGram
```

| Путь | Назначение |
| --- | --- |
| `SpaceGram/Settings`, `SettingsSignal` | Настройки продукта и реактивное состояние политик. |
| `SpaceGram/SettingsUI` | Центр SpaceGram и экраны настроек. |
| `SpaceGram/HistoryStorage`, `HistoryOverlay`, `HistoryIntegration` | Локальный захват правок/удалений и presentation-only overlay для аккаунта. |
| `SpaceGram/MediaArchive` | Проверяемое ограниченное хранилище полностью полученных медиа. |
| `SpaceGram/Privacy` | Политики режима «Призрак» и приватности. |
| `SpaceGram/Enhancements` | Сохранённые реализации с совместимыми идентификаторами и атрибуцией. |
| `SpaceGram/Strings` | Ресурсы локализации SpaceGram. |

Изменения upstream-кода отмечаются рядом с местом интеграции через `// MARK: NAGRAM`. См. [карту архитектуры](SpaceGram/SPACEGRAM_ARCHITECTURE_AUDIT.md) и [описание точек интеграции](SpaceGram/SPACEGRAM_HOOKS.md).

## Настройки по умолчанию и границы

Режим «Призрак», отложенная отправка, чтение при взаимодействии, кнопка форматирования, медиаархив, автоматические правила inline-ботов и дополнительные действия сообщений включаются только явно. Главный переключатель SpaceGram не создаёт поддельную серверную историю Telegram и не обходит членство, paywall, аутентификацию или серверные права на ресурс.

Медиаархив хранит только полные ресурсы, уже доступные аккаунту. Используются отдельный корень аккаунта, дедупликация по ресурсу, проверяемая временная запись и ограниченная очистка. Ресурс, который никогда не был загружен, восстановить нельзя.

Исходящий перевод изолирован по аккаунту и чату, по умолчанию выключен и сохраняет черновик при ошибке или пустом результате. Обычные запросы Telegram вида `@bot query` остаются штатными.

## Сборка и проверка

Поддерживаемая точка входа — `build-system/Make/Make.py`; режимы подписи и обязательная проверка устройства описаны в [docs/build.md](docs/build.md). Для полной iOS-сборки нужны macOS, закреплённая версия Xcode и подходящая конфигурация подписи.

Ручной [workflow SpaceGram iPhone Test Build](.github/workflows/spacegram-ios-test.yml) запускает portable-проверки и SpaceGram XCTest на `macos-15` с закреплённым Xcode. SIGTRAP только на завершении XCTest повторяется не более одного раза и лишь когда первая попытка одновременно доказала ноль XCTest failures, signal 5 и ненулевой код wrapper. Настоящие падения тестов не игнорируются.

Windows позволяет выполнить portable-проверки, но не подтверждает компиляцию iOS, подпись, установку и поведение на устройстве.

## Авторы и независимость

[Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS) предоставляет upstream-основу. В сохранённом коде на основе Nagram-iOS остаются авторские уведомления, атрибуция и совместимые имена; см. [BRANDING.md](BRANDING.md).

SpaceGram — независимый неофициальный проект. Он не связан с Telegram или Nagram, не одобрен ими и не является их официальным продуктом.
