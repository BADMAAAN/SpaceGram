# Legacy SpaceGram icon source

`SpaceGram-Graphite-Legacy.png` is the previous graphite primary icon retained
for provenance and possible future reference. It is not referenced by the iOS
application target.

`SpaceGram-Primary-Framed.jpeg` and `SpaceGram-Alternate-Framed.jpeg` are the
original device-feedback masters. Both contain a rounded tile inside an outer
black square. They are retained for provenance only; the current unframed PNG
masters live in `../IconSources/` and are used by the rendition generator.
